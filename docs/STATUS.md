# Sova status report

Last updated: 23 October 2026 (Devcenter Hacktober build phase, day 23; Phase 7, ready for judging: signed Android build, paid size for judging). Phases 4, 5 and 6 done early.

> Sova makes Ajo impossible to cheat, and turns your saving history into your credit history.

This file is the single source of truth for what exists, what is partly done, and what is not built.
Update it at the end of every phase.

## Product rules (do not change without discussion)

- **Sova never holds, moves, lends or invests money.** Members pay each other by bank transfer or cash; Sova keeps a tamper-evident record.
- **First users are self-run circles** (friends, colleagues, students). Collector/market mode is roadmap only.
- **Design:** flat, white-first with blue accents. No gradients, neon, glows or glass. Navy `#0B1A33`, royal blue `#1D4ED8`, mist `#F3F6FD`, logo sky blue `#7DC3E3`. Adire line patterns for African identity. Plus Jakarta Sans. Banking-grade neatness.
- **Honesty:** never invent stats, testimonials, partnerships or features. Anything not built is labelled "coming soon" or "roadmap".
- **Zero cost** except where explicitly agreed (Google Play $25, paid SMS later).

## RumptyCloud facts (observed 3 Oct)

- **Deployments** come from GitHub through the RumptyCloud GitHub App (granted only to `adeyanjufuhad/Sova`), from a chosen branch and root directory. Builds use Railpack. Auto-deploy on push is a checkbox.
- **Settings per deployment:** root directory, build command, start command, application type (Static Site/SPA or Web Service/Backend), health-check path (default `/`), port (default 8080; apps reading `$PORT` get it automatically), environment variables (bulk `.env` paste; all stored as secrets), persistent volume, autoscaling.
- **Sizes:** Free (5 apps, 0.5 vCPU, 512 MB, **always sleeps when idle**, ~8 s cold start), Tiny NGN 3.70/hr (~NGN 2,700/month), Starter NGN 7.40/hr, Scale, Pro. Scale-to-zero is optional only on paid sizes. CVE scan is a paid add-on ($0.50/deployment/month), turned off. Per-PR preview URLs are a paid add-on, off.
- **Live addresses (4 Oct):** API `https://sova-api.rumptycloud.app`, app `https://sova-app.rumptycloud.app` (branch `app-web`), website `https://sova.rumptycloud.app` (branch `site-web`, verify page at `/verify`). All Free size, auto-deploy on push. `CORS_ORIGINS` on the API lists the app and website.
- **Runtime gotcha:** the start command runs in `sh` without the image's PATH, so neither `npm` nor `node` is found. Working start command for the API:
  `export PATH="/mise/shims:$(echo /mise/installs/node/*/bin):$PATH"; exec node dist/server.js`
- **Build:** `npm ci && npm run build` with root `api`; only that folder is in the build context, so `db/migrations` is not copied into the image (migrations run from a laptop as the admin user).
- **API environment on RumptyCloud:** `NODE_ENV`, `LOG_LEVEL`, `DEMO_LOGIN_ENABLED`, `OTP_PROVIDER`, `OTP_TEST_NUMBERS`, `DATABASE_URL` (internal host `pg-c69bfa.db.rumpty.internal`, user `sova_app`), `JWT_SECRET`. `CORS_ORIGINS` to add once the app and website URLs exist.
- **Before judging:** Free apps cannot disable sleep. **Decided and switched 23 Oct:** the API, app and website are on Tiny with scale-to-zero off until 7 Nov, paid from the owner's RumptyCloud credit; back to Free after demo day. A plan change takes effect on the next deploy; saving the settings started one.
